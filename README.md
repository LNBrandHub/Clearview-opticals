# ClearView Opticals

A modern eyewear storefront with online shopping, cart, WhatsApp checkout, and appointment booking.

## Features

- Product catalog with category filtering (Men / Women / Unisex)
- Persistent shopping cart (localStorage)
- WhatsApp checkout & appointment requests
- Fully responsive design
- Accessible keyboard navigation

## Pages

| Page                | Description                        |
| ------------------- | ---------------------------------- |
| `index.html`        | Landing page with services and CTA |
| `shop.html`         | Product grid with category filters |
| `cart.html`         | Cart review with WhatsApp checkout |
| `appointments.html` | Appointment request form           |

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- No build step, no dependencies

## Run Locally

Just open `index.html` in a browser, or serve with:

```bash
python -m http.server 8000
```
